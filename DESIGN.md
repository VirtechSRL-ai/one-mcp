# Dashboard design
Operate mode. Quiet connection ledger: warm ivory background, graphite navigation, fine horizontal rules, green reserved for connected/success state. Typographic hierarchy rather than metric cards. Sidebar becomes a wrapping navigation on mobile. All data comes from the API; first run shows intentional empty states. Native labelled controls and visible focus. Dark theme honors system preference and explicit toggle. No decorative illustrations.

Tokens: --bg #f5f4ef; --fg #212922; --muted #59645b; --line #d3d9d1; --accent #146741; spacing 8/12/20/32/48; radius 12px. Font: self-hosted Geist via Next font package, system fallback for runtime resilience.
