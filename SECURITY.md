# Security policy

0.1.x is a developer preview; no independent security audit or production assurance is claimed. Do not put vulnerabilities or credentials into public issues. Use GitHub private vulnerability reporting where enabled; otherwise contact the repository owner through their published private contact before disclosing details. No dedicated security mailbox is invented here.

See docs/security/THREAT-MODEL.md for trust boundaries, mitigations and residual risks. The deployment guide lists exposure, key backup, public registration and crash-recovery constraints. Do not deploy unreviewed forks with real company credentials.
